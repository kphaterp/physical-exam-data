# Physical Exam Data

Mobile-friendly reference of evidence-based physical exam maneuvers with LR+/LR−, sensitivity and specificity — compiled primarily from the JAMA *Rational Clinical Examination* series.

Live site: https://kphaterp.github.io/physical-exam-data/

- `data.js` — all conditions and findings (edit here to add/update content)
- `index.html` — app (search, system filters, saved list, post-test probability calculator)
- Works offline after first load; add to iPhone Home Screen via Share → Add to Home Screen.

Reference aid only — verify values against primary sources.
